Platform

Visibility, Clarity and a Single Source of Truth

Accounting, CRM and inventory share one database. A change in one place shows everywhere.

Features

Accounting 5 features
General ledger
Journals and ledgers that update when each transaction is recorded.
Bills and invoices
Create, send and track bills and invoices from one screen.
Financial statements
Balance sheet, income statement and cash flow that are always up to date.
Multi-currency
Accounts and invoices in more than one currency.
Tax rates
Set the tax rates for each region. Tax is calculated on each line.
CRM 3 features
Leads
Record each lead and move it through a clear sales cycle.
Customers
One record for each customer, with contacts, invoices and notes.
Activity history
See each call, e-mail and meeting with a customer.
Inventory 3 features
Stock levels
Stock changes when a sale or a purchase is recorded. No manual counts.
Orders
Sales orders and purchase orders connect to stock and to the ledger.
Warehouses
Keep stock in more than one location.
Reports 3 features
Dashboards
Cash, debtors and sales on one screen.
Export
Print or export each report.
Public notes
Comments and footnotes on each report.
Security 2 features
Roles
Each user sees only what they need.
Audit log
Each change is recorded with the user and the time.
Access 2 features
Any device
The interface works on a desktop, a tablet and a phone.
Single sign-on
Sign in with your company account.
Multi-Tenancy 2 features
Multiple companies
One platform to manage many companies.
Full separation
The data of each company is kept separate.
